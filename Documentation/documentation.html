A) HTML Structure - top

This Template is a single page layout with all the pages placed inside the same HTML file index.html.
Each 'page' is a section tag with the class of 'page'. The ID of each section tag is used for the mobile navigation menu. 

<section class="page" id="page-id" >
  <header>
    <span class="title"> MENU TITLE </span>
  </header>
  <div class="content grid">
    <div class="page-header c12">
      <h1 data-value="About me"> PAGE TITLE </h1>
      <hr>
    </div>
    <div class="row">
      <div class="c12 end"> CONTENT </div>
    </div>
  </div>        
</section>

MENU TITLE Is whats displayed as the vertical text for each tab and PAGE TITLE Is whats displayed at the top of an open tab, data-value is used for the heading animation. The rest of your content can be placed in a row/column structure as above.

The template has classes for columns C1 through to C12, for example four columns per row you can use the classc3, three columns c4 class, two columns c6 class etc. The last column of each row should have the class end.

When modifying the amount of pages/sections. You will also need to adjust the CSS by going to line 160 in the main.css file located in the CSS folder. 

.page.active{
  width: calc(100% - 320px);
}

The 320px is based on 4 page headers at 80px each (About,Portfolio,Blog,Contact) The Home Page is not included.

Blog Pages

The Blog single post pages are loaded via AJAX, the content for those pages may be edited in the blog-single-1, 2 and 3 HTML files.

Contact Page

To Set up the contact form you will need to open the contact_mail.php file and change the following line to your email address.

$toEmail = "your_email@mail.com";

The address on the contact form can be modified by entering your latitude and longitude in lines 19 and 35 in main.js file located in the js folder. latlong.net Is a good site to find your latitude and longitude.

center:[40.712776, -74.005974],
let marker = new L.Marker([40.712776, -74.005974] , iconOptions);
Portfolio Page

For video or music portfolio items you will need to use the popup-iframe class and use the embed link from Youtube or Sound cloud.

<li class="popup-iframe" data-groups='["all","video"]'>

B) CSS Files and Structure - top

This template uses one CSS file main.css located in the CSS folder. If you would like to edit a specific section of the site, simply scroll down until you find the appropriate style that needs to be edited. The CSS is arranged in following order

  • 1 - Normalize
  • 2 - Base
  • 3 - Layout
  • 3.1 - Mouse Trailer
  • 3.2 - Columns
  • 3.3 - Navigation
  • 4 - Typography
  • 5 - Elements
  • 5.1 - Tiny Slider
  • 5.2 - Tabs
  • 5.3 - Skill Bar
  • 6 - Portfolio
  • 7 - Blog
  • 8 - Media Queries

The background image for the home page mouse trailer can be editied under 3.1 Mouse Trailer on the following line - 

background-image: url('../img/background.jpg');

Section 5 Elements, contains the main elements on the About page. The testimonial slider, client slider, icon boxes and the skill level bars.

C) JavaScript - top

This template has four Javascript files.

  1. jQuery
  2. leaflet.js
  3. script.js
  4. plugins.js
  1. jQuery is a Javascript library that greatly reduces the amount of code that you must write.
  2. Leaflet JavaScript library for mobile-friendly interactive maps.

  3. This file contains the plugin calls and some custom script. You shouldn't need to change much here apart from the home page text ticker text which can be modified on line 256 - 

    strings: ["web designer.", "front end developer.", "coffee drinker."],

    The address on the contact form can be modified by entering your latitude and longitude in lines 19 and 35. latlong.net Is a good site to find your latitude and longitude.

    center:[40.712776, -74.005974],
    let marker = new L.Marker([40.712776, -74.005974] , iconOptions);

    If you do change the name of the mouse trailer background image 'background.jpg' you will also need to update the following on line 12.

    image.src = "img/background.jpg";

    The Client Slider and Testimonial Slider at the top of the file use the Tiny Slider plugin which also supports several settings, the official documentation for the slider can be found at https://github.com/ganlanyuan/tiny-slider

  4. This contains all the plugins script.
